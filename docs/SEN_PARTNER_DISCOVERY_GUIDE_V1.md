# Sēn — Partner Discovery Guide V1

## 30-minute call structure

### 1. Understand business
- Core services
- peak/off-peak
- capacity model
- repeat customer model
- external aggregators
- pricing protection

### 2. Understand unused capacity
Ask for concrete times/services, not “do you have capacity?”

### 3. Understand economics
- retail price
- marginal cost
- acceptable incremental revenue
- payout preferences
- minimum guarantee expectations

### 4. Understand operations
- booking system
- check-in
- cancellations
- staff training
- reporting
- finance reconciliation

### 5. Test Sēn concept
Only now explain:
- premium curated membership
- controlled inventory
- no forced public discounting
- usage-linked pilot
- qualified members

### 6. Pilot reaction
Ask:
“What would need to be true for you to test this for 60–90 days?”

### Evidence grading
Strong:
- gives concrete inventory
- gives commercial ranges
- introduces operator/finance contact
- asks for pilot next steps

Weak:
- generic enthusiasm
- asks only for exposure
- refuses to discuss capacity/economics
