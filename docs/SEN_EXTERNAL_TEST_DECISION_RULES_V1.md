# Sēn — External Test Decision Rules V1

## Ship into pilot only if
- 80%+ book without founder explanation
- 80%+ correctly explain Free vs Included
- 70%+ understand Sēn Wallet credits
- 70%+ understand Flex Packs
- 70%+ understand when Core becomes better
- 70%+ rate AI as decision-helpful, not decorative
- location/memory trust issues are manageable
- no repeated critical misunderstanding about money or booking state

## Change before pilot if
- same confusion appears in 3+ independent participants
- Free is perceived as a weak trial instead of a real product
- Packs are preferred by heavy users because economics are too generous
- membership feels pushed before value is understood
- AI recommendations feel generic
- people cannot tell suggestion from confirmed action

## Kill or remove if
- feature adds complexity but participants do not value it
- feature has no measurable behavior change
- operational cost is high with weak user pull

## Founder discipline
One participant can reveal a bug.
Three can reveal a pattern.
Do not redesign from one person's taste.
