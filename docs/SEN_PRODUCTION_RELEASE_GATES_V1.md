# Sēn — Production Release Gates V1

## Alpha
Internal only.
Requirements:
- auth works
- partner/service/inventory data stable
- booking state machine tested
- ledger writes correctly
- refunds reversible
- audit logs present
- no AI action can claim success without tool result

5–10 invited members.
Requirements:
- manual fallback for every critical workflow
- support owner assigned
- partner contact path
- incident log
- payout reconciliation
- test bookings completed

Requirements:
- pilot gates from Validation/Pilot phase met
- legal docs reviewed
- payment production configuration
- privacy notice
- partner agreements
- support and refund policy
- monitoring / alerts

- repeated booking reliability
- partner payout accuracy
