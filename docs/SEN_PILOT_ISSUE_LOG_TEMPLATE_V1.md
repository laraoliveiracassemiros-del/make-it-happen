# Sēn — Pilot Issue Log Template

For every meaningful issue capture:

- Date/time
- Member ID
- Partner
- Booking/service
- Severity P0/P1/P2/P3
- Category
  - booking
  - access/check-in
  - payment/refund
  - partner reliability
  - AI action
  - social/safety
  - privacy
  - other
- What happened
- Member impact
- Immediate containment
- Money/benefit state
- Root cause
- Owner
- Resolution
- Time to resolve
- Preventive change
- Repeated issue? Y/N
