# Sēn — Free + Membership Architecture V4

## Core principle
Sēn Free is a real product, not a crippled demo.
Membership is the economically obvious upgrade after real use.

Free account → useful behavior → pay-per-use → visible savings/access gap → Core / Plus / Black.

## Sēn Free
Free users can:
- complete 8-question personalization
- use Sēn AI
- browse Explore
- save preferences and edit memory
- receive contextual nearby suggestions (opt-in location)
- join Circles and Squads
- connect calendar
- book eligible open-access experiences
- pay per class/service
- access selected Sēn Price offers
- receive campaign coupons / wallet credits
- buy selected Flex Packs
- see transparent savings-to-membership comparisons

Free users do NOT receive:
- Included studio allowance
- full premium gym network access
- monthly Privileges
- recurring Signature access
- recurring Guest passes
- higher booking priority / horizons
- premium Boost allocation
- Black concierge treatment

## Pay-per-use
Every eligible experience can have:
1. Public price
2. Sēn Free price
3. Member price
4. Included state for eligible memberships

Example:
Reformer retail: R$ 90
Sēn Free: R$ 78
Core: Included when eligible
Plus/Black: Included when eligible

The user always sees money in BRL. No opaque token economy.

## Flex Packs
Optional, non-subscription bridge product for Free users.

Examples:
- 3 Studio Passes — R$ 219 — 45-day expiry
- 5 Studio Passes — R$ 349 — 45-day expiry
- 10 Studio Passes — R$ 649 — 60-day expiry

Packs apply only to eligible inventory/categories.
They should never become cheaper than membership at sustained monthly usage.

## Credits / Coupons
Use transparent wallet credits in BRL, not abstract credits.

Sources:
- welcome campaign
- referral
- partner-funded promotion
- service recovery
- reactivation campaign
- milestone campaign

Examples:
- R$ 20 Sēn Wallet credit
- 10% off one booking, capped at R$ 20
- R$ 40 off Core for first 2 months

Do not create secret individualized base prices.

## Conversion logic
Membership should be recommended when evidence supports it.

Triggers:
- 2+ paid studio bookings in 14 days
- Free spend reaches R$ 250–300 in a rolling month
- user repeatedly tries member-only inventory
- savings opportunity exceeds meaningful threshold
- user buys a second Flex Pack
- recurring behavior suggests predictable plan value

Example:
"You've spent R$ 286 on eligible visits this month. Core would have cost R$ 399 and would include up to ~8–9 eligible studio visits plus gym access and 1 Privilege."

## Membership recommendations
Recommendations are contextual, not forced.

Core:
- everyday value
- selected premium gym access
- ~8–9 eligible studio visits/month
- member pricing
- 1 Privilege/month
- better booking rules

Plus:
- ~17–18 eligible studio visits/month
- broader network
- 2 Privileges/month
- selective Signature access
- more coworking / boosts

Black:
- ~25–26 eligible studio visits/month
- controlled Signature access
- 3 Privileges/month
- Guest
- premium concierge / proactive support
- best booking horizons

## AI role
Sēn AI should:
- understand user goals and constraints
- remember editable preferences
- learn from explicit feedback and behavior
- use optional location context
- explain why suggestions appeared
- recommend free vs paid options honestly
- calculate when membership is economically better
- never invent a booking success
- never hide pricing or discount logic

## Location intelligence
Opt-in only.
Examples:
- "You're near Asa Sul. Boxing starts at 16:30, 12 min away."
- "You usually prefer lighter sessions on Sundays. There is reformer at 18:00 near you."

Controls:
- Always / While using / Off
- pause proactive suggestions
- "Why am I seeing this?"
- exact location never exposed socially

## App states
### Free state
Home:
- personalized day
- nearby/contextual recommendations
- pay-per-use prices
- savings meter
- membership recommendations only when relevant

Explore:
- Public / Sēn Price / Member Price / Included labels
- filters for Free-accessible inventory

Wallet:
- Sēn Wallet BRL credits
- coupons
- Flex Packs
- monthly Free spend
- potential membership savings

### Member state
Same app, but:
- Included states appear
- allowances / privileges / access expand
- higher booking horizons
- richer wallet value
- better inventory access
- plan management

## UX principle
Do not maintain separate apps for Free vs Member.
Maintain one Sēn product with different entitlement states.

The transition should feel like:
"I already use this. Membership simply makes it dramatically better."

## Key economics guardrail
Free discounts and packs must preserve the point at which Core becomes obviously better around sustained usage.

Target conversion intuition:
- 0–2 paid experiences/month: Free makes sense
- 3–4 experiences/month: user begins seeing Core advantage
- 5+ eligible experiences/month: Core should usually be economically and experientially superior
- heavy users should naturally sort into Plus/Black based on real behavior
