# Sēn — Experiment Registry V1

## EXP-001 — Free booking comprehension
Hypothesis: A new user understands that Sēn Free is pay-per-use.
Metric: 80% explain it correctly after one booking.
Kill/change: If <65%, simplify pricing states.

## EXP-002 — Sēn Price
Hypothesis: Sēn Price creates useful Free value without making membership unnecessary.
Metric: Users perceive Free as valuable but still understand the membership advantage.
Kill/change: If users interpret Sēn as only a discount marketplace, reduce discount emphasis.

## EXP-003 — Flex Packs
Hypothesis: Packs bridge Free → Membership for occasional users.
Metric: Users understand Packs as non-recurring and limited.
Kill/change: If >30% prefer Packs at heavy monthly usage, economics or packaging must change.

## EXP-004 — Core conversion moment
Hypothesis: Around 5 eligible experiences/month, Core becomes clearly better.
Metric: Users independently identify Core as better near that usage.
Kill/change: Reprice / change entitlements if the crossover is unclear.

## EXP-005 — AI usefulness
Hypothesis: Sēn AI is meaningfully more useful when it combines preference, price, time and location.
Metric: 70%+ say the AI changed or simplified a real decision.
Kill/change: If it feels like a search bar, redesign the action layer.

## EXP-006 — Editable memory
Hypothesis: Visible memory increases trust.
Metric: 80%+ understand they can edit/remove remembered preferences.
Kill/change: If memory feels invasive, reduce persistence and improve consent.

## EXP-007 — Nearby proactive suggestions
Hypothesis: Opt-in nearby suggestions feel helpful.
Metric: 65%+ positive / neutral comfort and clear permission understanding.
Kill/change: If perceived as creepy, default to less precise context.

## EXP-008 — Partner inventory
Hypothesis: premium partners will release selected capacity without public discounting.
Metric: 8+ of first partner conversations discuss a plausible pilot.
Kill/change: If inventory only comes with destructive economics, revise supply model.
