# Sēn — External Test Moderator Kit V1

## Objective
Run the first external prototype tests without teaching the product.

## Moderator opening
Say:
"You’re testing the product, not yourself. If something is confusing, that is useful for us. Please think out loud. I’m going to avoid helping unless you are completely stuck."

Do not pitch Sēn before the tasks.

## What to observe
For each task record:
- completed without help
- completed with hesitation
- completed with help
- failed / abandoned
- time to first meaningful action
- exact confusion
- exact phrase participant uses
- what they expected to happen
- what actually happened

## Red flags
- asks what "Sēn Price" means after seeing it repeatedly
- thinks Flex Packs are a subscription
- believes Free includes unlimited classes
- assumes Circle join equals class booking
- thinks AI already booked without confirmation
- cannot find Wallet
- cannot explain Core after comparison
- location suggestion feels invasive
- memory feels permanent or hidden

## Post-test questions
1. In one sentence, what is Sēn?
2. What can you do without paying a monthly membership?
3. What is Sēn Price?
4. When would Core become better for you?
5. Would you buy a Flex Pack? Why or why not?
6. What felt most valuable?
7. What felt unnecessary?
8. What felt confusing?
9. Did the AI feel like a chatbot, search engine or real assistant?
10. What would need to be true for you to pay today?

## Money probe
Do not ask only "Would you pay?"

Ask:
- "If Sēn launched tomorrow, what would you personally spend on it next month?"
- "What would you stop paying for to make room for it?"
- "Would you pay R$399 for Core today? What is missing for the answer to become yes?"
- "Would you rather buy 5 visits for R$349 or Core for R$399? Why?"

## Evidence grading
A — paid / deposit / concrete commitment
B — serious pilot commitment with date or action
C — says would buy under explicit condition
D — likes concept but avoids commitment
E — confused / uninterested / not target

## Session close
Do not defend the product.
Ask for one final sentence:
"If you could change one thing before this launched, what would it be?"
