# Sēn — Validation CRM Schema V1

## Purpose
Track evidence from member and partner validation without mixing opinions, behavior and commitments.

## Member record
- Participant ID
- Age bracket
- Neighborhood
- Current monthly wellness spend
- Categories currently used
- Existing memberships
- Date / channel
- Interviewer
- Prototype task set
- Task completion without help
- Confusion points
- Exact phrases worth preserving
- Price reaction
- Strongest commitment signal
- Would pay now? yes / no / conditional
- Free vs Core interpretation
- Flex Pack interpretation
- AI usefulness score
- Memory / location comfort
- Repeat intent
- Evidence score 0–12
- Next action

## Partner record
- Partner ID
- Venue
- Category
- Neighborhood
- Contact role
- Discovery date
- Off-peak / underfilled capacity
- Current public price
- Current third-party distribution
- Willingness to release inventory
- Preferred economics model
- Check-in method
- Cancellation constraints
- Settlement preference
- Pilot interest
- Risks / exclusivity
- Evidence score 0–12
- Next action

## Statuses
Members:
- To recruit
- Scheduled
- Interviewed
- Usability complete
- Strong signal
- Weak signal
- Rejected hypothesis

Partners:
- Not contacted
- Discovery booked
- Discovery complete
- Pilot plausible
- Pilot ready
- Hold
- Reject

## Evidence hierarchy
1. Payment / deposit
2. Signed or concrete pilot commitment
3. Test booking / repeated behavior
4. Strong conditional commitment
5. Stated willingness
6. Compliment / enthusiasm

Never treat "this is cool" as demand.
